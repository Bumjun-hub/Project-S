# 포트폴리오 화면 캡처

구현된 Next.js 화면을 Playwright Chromium으로 캡처합니다. 이미지 생성 도구로 만든 목업이 아닙니다.
상품·추천 결과는 데모 데이터이며 실제 JWT 인증·PostgreSQL 저장을 증명하는 이미지는 아닙니다.
새 브라우저 컨텍스트에서 예시 계정으로 로그인·실측 등록·추천·피드백·기록 새로고침을 실제 UI로 수행합니다.
운영 계정·DB는 사용하지 않으며 브라우저의 모든 `/api/` 요청은 차단하고 발생 시 실패 처리합니다.

## 다시 캡처하기

`frontend`에서 실행합니다. 문서용 PNG 8개가 이 폴더에 생성되며, 재실행하면 같은 파일을 갱신합니다.

```powershell
npm ci
npx playwright install chromium
npm run screenshots
```

- 데스크톱: 1440×1000 뷰포트
- 모바일: 390×844 뷰포트, Chromium 모바일 에뮬레이션(실제 기기/Safari가 아님)
- 전체 페이지 PNG, reduced-motion, 한국어, Asia/Seoul 시간대
- 별도 데모 서버: `127.0.0.1:3100`, 일반 프론트의 `.next`와 분리된 `.next-e2e` 빌드
- `.env.local`을 수정하지 않으며 기존 서버를 재사용하지 않음
- 로딩·폰트·이미지 표시 완료 및 가로 넘침을 확인한 후 캡처

기존 CI의 E2E 테스트와 별도 실행합니다. PNG에는 촬영 시점의 데모 기록 시각이 포함될 수 있습니다.
프로젝트 루트 README가 이 폴더의 이미지 파일을 상대 경로로 참조합니다.
